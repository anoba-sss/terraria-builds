## Режим редактирования (только владелец)
- Шестерёнка справа вверху → «Настройки редактирования».
- Нужен GitHub fine-grained токен с правом «Contents: Read and write» только на репозиторий сайта.
- Токен хранится только в localStorage браузера владельца. Без токена сайт работает только на чтение.
- Сохранение делает коммит в `data/builds.json` и `data/items.json`. GitHub Pages обновит сайт через 1–2 минуты.
- В редакторе: описание, английское название, ссылка на вики, статус, рецепты (станция и ингредиенты), детали брони с рецептами, дропы, получение.
- В билдах: добавить предмет в категорию этапа, убрать предмет из этапа (×).
