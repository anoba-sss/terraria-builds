## Режим редактирования (только владелец)
- Шестерёнка справа вверху → «Настройки редактирования».
- Нужен GitHub fine-grained токен с правом «Contents: Read and write» только на репозиторий сайта.
- Токен хранится только в localStorage браузера владельца. Без токена сайт работает только на чтение.
- Сохранение делает коммит в `data/builds.json` и `data/items.json`. GitHub Pages обновит сайт через 1–2 минуты.
- В редакторе: описание, английское название, ссылка на вики, статус, рецепты (станция и ингредиенты), детали брони с рецептами, дропы, получение.
- В билдах: добавить предмет в категорию этапа, убрать предмет из этапа (×).

## Редизайн v5: пиксельный стиль и темы классов
- 🎨 → «Макет»: переключатели «Пиксельный стиль» и «Цветовая тема под выбранный класс». Оба включены по умолчанию; если выключить оба, сайт выглядит как раньше. 🎨 → «Показ»: «Значки боссов слева от номера этапа».
- Темы: Воин (янтарь, бронза, сталь), Маг (сине-фиолетовый, звёзды), Призыватель (бирюза, джунгли), Стрелок (песочное золото, оружейная сталь). Заданы в css/style.css (`body.ct[data-class=…]`). Пока тема класса включена, палитра из 🎨 → «Цвета» и «Цвета классов» не используется.
- Редкость предмета: необязательное поле `rarity` (-1…11) в items.json, задаётся в редакторе предмета. Цвет рамки при наведении берётся из редкости; без неё — цвет класса. Заполнено ни у одного предмета.
- Значки боссов у этапов: условные пиксельные символы (js/app.js, GLYPHS). Свои картинки: положить в images/bosses/ и вписать путь в BOSS_IMG.
- Заголовки: Pixelify Sans (в 🎨 → «Шрифты» можно заменить). Основной текст прежний.

## v5.1: флаги, положение картинок, шрифты
- 🎨 → «Флаги»: выбрать флаг, перерисовать по клеточкам 8×8 (цвет рисунка / тёмная деталь / стереть), покрасить рисунок, детали, фон и верхнюю полосу; можно задать свою картинку. Блок «Для всех флагов» красит сразу все флаги без своего цвета. Хранится в site.json (`flags`).
- Редактор предмета: «Положение картинки в ячейке» — масштаб и сдвиг ползунками, кнопка «⊙ По центру (авто)» сама находит предмет на картинке и ставит по центру. Хранится в items.json (`imgFit`).
- Шрифты: заголовки — Philosopher, подписи и вкладки — Golos Text, цифры этапов — Pixelify Sans.
