# Terraria Builds

Справочник билдов для подготовки к боссам Terraria: броня, оружие, аксессуары и баффы по классам (воин, маг, призыватель, стрелок), с рецептами и информацией о дропе.

Сайт: https://anoba-sss.github.io/terraria-builds/

Данные: [Terraria Wiki](https://terraria.wiki.gg/ru/), [Террария вики (Fandom)](https://terraria-game.fandom.com/ru/wiki/). Фанатский проект, не связан с Re-Logic.
